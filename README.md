# LongTermManager

一个纯本地、轻量的订阅续费与长期到期事项管理器。

专门记录那些：

> 现在不用处理，但未来某一天绝对不能忘的事情。

例如：

- 软件订阅
- VPS / 服务器续费
- 域名续费
- 保险
- 证件到期
- 合同到期
- 设备保修
- 长期周期事项
- 其他一次性长期提醒

---

## 特点

### 📅 长期事项管理

支持：

- 一次性事项
- 每月
- 每 3 个月
- 每 6 个月
- 每年
- 自定义天 / 月 / 年周期

自动计算：

- 还有多少天
- 今天到期
- 已逾期多少天

---

### 🔁 自动续期计算

循环事项点击「已续费」后，可自动计算下一次日期。

支持：

- 按原到期日顺延
- 按实际处理日顺延
- 月底 31 日自动适配
- 闰年 2 月 29 日处理
- 逾期多个周期后自动跳到第一个未来周期

---

### 🔔 浏览器提醒

可以为每条事项设置提醒节点，例如：

```text
30, 7, 1, 0
表示：

提前 30 天
提前 7 天
提前 1 天
到期当天

分别提醒。

如果错过某个提醒节点，下次打开浏览器时会补提醒。

逾期事项会继续提醒，直到处理。

💤 稍后提醒

支持暂时关闭某条事项的网页提醒：

1 天后
3 天后
7 天后

不会修改真正的到期日期。

🗂 卡片式管理

事项按照紧急程度自动分组：

已逾期
7 天内
30 天内
90 天内
90 天以上

远期事项默认折叠，减少页面滚动。

🔎 搜索与筛选

支持：

名称搜索

时间范围
自定义日期范围
循环 / 一次性事项

🔐 完全本地

LongTermManager 不需要：

注册账号
登录
云服务器
在线数据库

所有事项数据保存在 Tampermonkey 本地存储中。

脚本不会读取或分析正在浏览网页的正文内容。

💾 数据安全

支持：

JSON 完整备份

建议定期导出 JSON 备份。

安装
环境

需要安装：

Chrome / Edge 等 Chromium 浏览器
Tampermonkey
手动安装
下载 LongTermManager.user.js
打开 Tampermonkey
进入「管理面板」
打开「实用工具」
选择「从文件导入」
导入 LongTermManager.user.js
完成安装

安装后：

点击 Tampermonkey 菜单中的：

打开长期事项管理器

即可进入管理页面。

数据迁移

完整数据可以通过 JSON 在不同电脑之间迁移：

旧电脑
↓
导出 JSON
↓
新电脑安装 LongTermManager
↓
导入 JSON

即可恢复事项、分类、设置、历史记录等数据。

设计原则

LongTermManager 不准备成为一个复杂的 Todo 或记账软件。

它只专注于一个问题：

管理那些几个月、几年以后才需要处理，但绝对不能忘记的事情。

因此项目会尽量保持：

极简
本地
低干扰
易备份
长期稳定
